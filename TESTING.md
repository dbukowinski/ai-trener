# Testing the package

Thank you for testing! Feedback from real use is the most valuable: what worked, where the AI got it wrong, what was missing.

## How to test (30–60 minutes)

1. Install the package per `README.en.md` (pick one route: Claude with the skill, local folder, Google Drive or ChatGPT).
2. Write "Install AI Coach" and go through the whole installation with **your own** data (or made-up data — then say so in your report).
3. Ask for a one-week plan and check whether it reached your watch (if your platform allows it).
4. Do 2–3 everyday things: move a day, log a session, "weekly review".
5. (Optional) Run a few scenarios from `skill/ai-coach/evals/scenarios.md` — especially the ⚠ ones.

## What to check

- [ ] Could you go through the questionnaire comfortably on a phone (one question at a time, answer with a digit)?
- [ ] Was anything unclear (abbreviations, jargon, technical instructions)?
- [ ] Was the questionnaire clear and not too long?
- [ ] Did the methodology proposal fit your goal and life? Did the AI ask about favourite coaches?
- [ ] Did the plan respect your constraints (days, terrain, equipment)?
- [ ] Did the plan reach your watch? If not — did the AI clearly say what to enter manually?
- [ ] Were the project files created where you wanted?
- [ ] Did the AI say "saved" only when saving succeeded?
- [ ] Was anything unsafe or untrue?

## Reporting feedback

Open an issue in the repository — the "Tester feedback" template tells you what to include. **Don't paste health or personal data** — a description of the situation is enough.

Include: AI client (Claude / ChatGPT / Claude Code / other), watch and write route, package version (`package_version` in `00 Start.md`), what happened vs what you expected.
